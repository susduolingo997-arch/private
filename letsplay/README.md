# SHARDWILD — "Completely Normal Survival Playthrough" (animated Let's Play)

A 5-minute, fully procedural, animated YouTube-style Let's Play of **Shardwild**, an original,
fictional voxel survival game. Everything — world, characters, creatures, textures, UI, music,
sound effects and narration timing — is generated by code in this folder.

| Time | Chapter |
|------|---------|
| 0:00 | Starting the world — spawn, punch a tree (it floats), craft a Twig Mallet |
| 0:40 | Exploring — Burble village, a trade, a Fizzberry Bomb, "renovations" |
| 1:30 | The cave — glowshards, glimmerbugs, and a Hexapede that has SO many legs |
| 2:20 | Building — the greatest house ever (towers, windows, a statement door) |
| 3:10 | Night — two moons, Grumblecubes and Stiltwraiths, the wall, the panic |
| 4:10 | Ending — dawn on the roof, one ugly block, total collapse, freeze-frame, logo |

## Pipeline
1. `narration.py` – Kokoro TTS (voice `am_puck`) renders every script line → `build/cues.json`.
2. `audio.py` – places narration (auto-resolving overlaps), synthesizes all SFX and the
   procedural soundtrack with numpy, ducks music under speech, writes `build/audio.wav`
   and the facecam mouth envelope `build/env.json`.
3. `scene.js` – Three.js voxel scenes + 2D HUD/facecam/captions compositor; `renderAt(t)` is
   fully deterministic. `events.json` is the shared timeline used by both picture and sound.
4. `render.mjs` – drives headless Chromium and pipes frames into ffmpeg.

```bash
python3 narration.py <dir with kokoro.onnx + voices.bin>
python3 audio.py
node render.mjs 0 300 build/video.mp4          # or split into chunks and concat
ffmpeg -i build/video.mp4 -i build/audio.wav -c:v copy -c:a aac -b:a 192k shardwild_letsplay.mp4
```
